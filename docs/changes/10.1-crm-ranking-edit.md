# Versão 10.1 — edição e exclusão de lançamentos automáticos

## Comportamento

- Lançamentos criados pelo CRM continuam identificados como automáticos.
- É possível editar vendedor, cliente, cidade, valor e data pelo formulário do ranking.
- Uma edição recebe a identificação `Automático do CRM — editado manualmente` e não é sobrescrita por atualizações comuns da oportunidade.
- A ação Excluir retira o lançamento dos totais, mas aplica cancelamento lógico e preserva origem, valor, usuário e data para auditoria.
- A exclusão não remove nem altera a oportunidade do CRM.
- Se a oportunidade deixar de ser ganha e depois voltar para ganho, o vínculo é reativado com os dados atuais do CRM.

## Rollback

Reverter para o commit `63fef8f` remove os controles de edição/exclusão automática sem apagar registros. Dados cancelados devem permanecer preservados.
