# Versão 10.0 — ganho do CRM integrado ao ranking

## Objetivo

Ao registrar uma oportunidade como ganha, criar ou atualizar o lançamento correspondente no ranking de vendas usando o responsável, o cliente, o valor e a data do ganho.

## Regras

- O lançamento possui identificador determinístico baseado na oportunidade, impedindo duplicidade por repetição ou troca de usuário.
- O vendedor vem do responsável da oportunidade, nunca do usuário que clicou na ação.
- Alterações futuras no ganho atualizam o mesmo lançamento.
- Ao retirar a oportunidade da etapa de ganho, o lançamento automático é cancelado e excluído dos totais, mas permanece armazenado para auditoria.
- Lançamentos manuais não são modificados pelo fluxo automático.
- O fluxo não cria lançamentos retroativos para ganhos anteriores à versão 10.0.

## Rollback

O código anterior está marcado pela tag local `backup/pre-crm-ranking-auto-20260824`. Reverter o código não deve excluir lançamentos já gravados. Uma eventual reversão de dados deve ser tratada separadamente e somente após revisão.

## Publicação

Primeiro testar no desktop. Publicar no Vercel somente após aprovação explícita da homologação local.
